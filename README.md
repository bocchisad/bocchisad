### Featured project

**[cv-desk](https://github.com/bocchisad/cv-desk)** — control your Mac desk with hand gestures.

macOS 13+ menu-bar app powered by **MediaPipe Hands**: play/pause, volume, Spaces, Mission Control, App Exposé, screenshots — mapped from a small deliberate gesture set, with per-app profiles.
